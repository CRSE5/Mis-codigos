    <h1>Navegador</h1>

    <p><strong>Un navegador web (o browser)</strong> es una aplicación de software que permite a los usuarios acceder a contenido en la World Wide Web.
    Los ejemplos mas destacador incluyen: </p>
    <ul>
        <li><b>Google Chrome:</b> Desarrollado por googlr, es el navegador más popular a nivel mundial por su velocidad y amplia compatibilidad.</li>
        <li><b>Mozila Firefox:</b> Conocido por su código abierto, su enfoque en la privacidad y la seguridad del usuario.</li>
        <li><b>Microsoft Edge:</b> Basado en chromium, es el navegador estándar en sistemas Windows, ofreciendo integración con servivios de Microsft.</li>
        <li><b>Brave:</b> Un navegador enfocado en la privacidad, que bloquea anuncios y rastreadores por defecto.</li>
        <li><b>Safari:</b> El navegador predeterminado de los Apple(iOS y macOS), optimizado para la eficiencia energetica.</li>
    </ul>

    <h2>Framework</h2>

    <p><strong>Un Framwwork</strong> es una estructura o marco de trabajo predefinido que facilita el desarrollo de software al proporcionar componentes, reglas y herramientas comunes, evitando que el programador tenga que "reinventar la rueda" desde cero. Se aplican en diversas áreas de desarrollo: </p>
    <ol>
        <li><b>Desarrollo Web(Front-end):</b> <i>React, Vue.js y Angular </i> crear interfaces de usuarios dinámicas.</li>
        <li><b>Desarrollo Web(Back-end):</b> <i>Django(Python), Laravel(PHP) y Ruby on Rail</i> para gestionar bases de datos, rutas y lógica del servidor.</li>
        <li><b>Desarrollo Móvil:</b> <i>Flutter y React Native</i> para construir aplicaciones multiplataforma con una sola base de código.</li>
        <li><b>Ciecia de Datos:</b> <em>TensorFlow</em> para el entenamiento de modelos de aprendizaje automático</li>
    </ol>

    <h3>HTML</h3>

    <p><strong>HTML (Lenguaje de Marcadao de Hipertexto)</strong> es el estándar utilizado para estructurar y definir el contenido de las páginas web mediante etiquetas. <em>No es un lenguaje de programación</em>, sino de marcado, cuyo propósito principal es indicar al navegador cómo organizar elemntos como textos, imágenes, enlaces y multimedia. Ejemplo de Etiqutas comunes: </p>
    <ul>
        <li><b>De < h1 > a < h6 >:</b> Para definir encabezados de distintos niveles jerárquicos.</li>
        <li><b>< p >:</b> Para crear párrafos de texto.</li>
        <li><b>< a >:</b> para incrustar hipervínculos hacia otras páginas o recursos.</li>
        <li><b>< img >:</b> Para incrustar imágenes en el documento.</li>
        <li><b>< div > y < span >:</b> Contenedores genéricos para agrupar elementos o texto en línea.</li>
    </ul>

    <h4>Frontend</h4>

    <p><strong>El fronend</strong> es la parte visible y accesible de un sitio web o aplicación con la que lps usuarios interactúan directamente, conocida como el lado del cliente. Se encarga de la estructura, el deiseño visual, la interactividad y la experiencia de usuarios, utilizando principalmente los lenguajes HTML(estructura), CSS(estilos) y JavaScript(comportamiento dinámico).
    </p>
    <ul>
        <li><b>Interfaz de usuario:</b> Botones, menús de navegación, formularios, imágenes, textos. colores, tipografías y animaciones</li>
        <li><b>Interactividad:</b> Validación de formularios en tiempo real, efectos de animación sin recargar la página (AJAX)y actualizaciones dinámicas de contenido.</li>
        <li><b>Adaptabilidad:</b> Diseño responsivo que ajusta la visualización a diferentes dispositivos (móviles, tabletas, ordenadores) y navegadores.</li>
        <li><b>Aplicaciones reales:</b> La pantalla de inicio de Netflix con sus listas a diferentes películas, la interfaz de Google Maps para explorar ubicaciones, o la página de productos de una tienda online con el carrito de compras.</li>
    </ul>

    <h5>Plataforma digital</h5>

    <p><strong>Una plataforma digital</strong> es una infrestructura basada en software o un entorno virtual que actúa como intermediario, permitiendo la interacción, transacción o coordinacón entre dos o más grupos de usuarios (como productores y consumidores) a través de internet. A diferencia de una página web estática, una plataforma facilita actividades dinámicas como comprar, vender, comunicarse o aprender en tiempo real. Los principales tipos y ejemplos incluyen: </p>
    <ul>
        <li><b>Redes sociales:</b> Conectan usuarios para compartir contenido e interactuar; ejemplos: Facebook, Instagram, X (Twitter), Linkedln.</li>
        <li><b>Comercio electronico (E-comerce):</b> Facilita la compra y venta de bienes o servicios; ejemplos: Amazon, Mercado Libre, eBay.</li>
        <li><b>Streaming y entretenimiento:</b> permiten el acceso a contenido multimedia bajo demanda; ejemplos: Netflix, Spotify, Youtube.</li>
        <li><b>Educativas:</b> ofrecen recursos, clases, y getión académica a distancia; ejemplos: Moodle, Google Classroom, Coderhouse.</li>
        <li><b>Movilidad y servicios:</b> Conectan proveedores de servicios con usuarios; ejemplos: Uber, Airbnb.</li>
        <li><b>Mensajeria y videoconferencia:</b> Habilitan la comunicación instantánea y remota; ejemplos: WhatsApp, Zoom, Microsoft Teams.</li>
        <li><b>Pagos y finanzas:</b> Gestiona transacciones económicas digitales; ejemplos: PayPal.</li>
    </ul>

    <h6>Ciberespacio</h6>

    <p><strong>El ciberespacio</strong> es un entorno virtual e intangible creado por la interconexión de redes informáticas, sistemas de comunicación digital y plataformas en línea donde se almacena, intercambia y procesa información. A diferencia del espacio físico, no tiene existencia material ni limites geográficos fijos, aunque depende de hardware y software subyacentes; el término acuñado en 1984 por el escritor William Gibson en su obra <i>Neuromancer</i>.</p>
    <ul>
        <li><b>Redes sociales:</b> Plataformas como Facebook, Instagram o X (Twitter), donde los usuarios interactúan y comparten contenido.</li>
        <li><b>Comercio electrónico:</b> Sitios web como Amazon que facilitan transacciones comerciales digitles.</li>
        <li><b>Servicios financieros:</b> Aplicaciones de banca en línea, PayPal o sistenas de pago digital que permiten transacciones seguras.</li>
        <li><b>Comunicación corporativa:</b> intranets privadas y herramientas de mensajería empresarial que permiten a las organizaciones operar de forma segura.</li>
        <li><b>Juegos en línea:</b> Entornos multijugador masivos donde los jugadores interactúan en tiempo real a través de dispositivos remotos.</li>
    </ul>
